เตรียมข้อมูลก่อนรับพัสดุ

ให้บอทรู้ว่าพัสดุเป็นของใคร

สำหรับผู้รับพัสดุ

  1. เปิด Telegram ค้นหาชื่อบอทที่ผู้ดูแลสร้าง แล้วกด Start หรือส่ง /start
  2. ส่งชื่อที่ใช้บนป้ายพัสดุ เช่น สมชาย ใจดี รอข้อความยืนยันลงทะเบียน
  3. ส่ง /addparcel แล้วส่งเลขพัสดุ เช่น JTTH203447892502 หรือส่ง /addparcel JTTH203447892502 ในข้อความเดียว
  4. รอคำตอบว่า “บันทึกแล้ว” ใช้ /myparcels เพื่อตรวจเลขที่ยังรอรับ
  5. เมื่อจุดรับสแกนเลขนี้ ระบบจะบันทึกภาพและส่งข้อความมาที่แชทของคุณ

เพิ่มเลขใหม่ทุกครั้งที่สั่งของ ให้เลขตรงกับบาร์โค้ดบนกล่อง หากเลขไม่ตรงจะยังบันทึกรับให้ไม่ได้

สำหรับผู้ดูแล

ตั้ง Telegram token ในไฟล์ .env บนเครื่อง แล้วเปิด start_bot.bat ค้างไว้หนึ่งหน้าต่าง บอทกับเว็บต้องใช้ Firebase โปรเจกต์เดียวกัน

หา username ของบอทได้จาก Telegram → @BotFather → /mybots แล้วเลือกบอทของคุณ

หลังแก้ token ให้เปิดบอทและเว็บใหม่ หน้าสแกนบนเว็บทำงานได้โดยไม่ต้องเปิด main.py

หากบอทไม่ตอบ ให้ตรวจหน้าต่าง start_bot.bat และตรวจว่าใช้ token ของบอทตัวเดียวกับที่ผู้รับเปิดแชทอยู่
